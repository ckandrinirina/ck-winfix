WinFix

One Windows program that repairs common Windows problems by itself, cheapest fix first. If something is still broken, it can reinstall or reset Windows and keep your personal files.

Download

WinFix.exeWindows, 64-bit WinFixUsb-macos-arm64Mac with an Apple chip (M1 or newer) WinFixUsb-macos-x64Mac with an Intel chip

The files are not signed, so Windows or macOS may warn you when you open them. Windows must still start to use WinFix.exe.

What it fixes

  • No taskbar, or a screen that flashes every few seconds because Explorer keeps crashing.
  • Windows Update is broken: its service is turned off, or updates keep failing to install.
  • Blue screens: two or more crashes in the last 7 days.
  • Disk errors or damaged system files.
  • The Start menu, Search or Settings will not open.
  • Windows signed you in with a temporary profile, so your files and settings seem gone.
  • The network adapter is on, but no website can be reached.

WinFix resets Windows only if a problem is still there after every fix. It explains what will happen and waits until you type YES. Every reset keeps your personal files.

How to start it as administrator

WinFix needs administrator rights. This way works even when the taskbar is gone.

  1. Press Ctrl+Shift+Esc to open Task Manager.
  2. Click Run new task.
  3. Type the full path to WinFix.exe, for example C:\Users\you\Downloads\WinFix.exe.
  4. Tick Create this task with administrative privileges.
  5. Click OK.

To rehearse first, run WinFix.exe --dry-run. It shows what WinFix would do and changes nothing.

Only have a Mac?

If your PC no longer starts, WinFixUsb writes a bootable Windows install USB from your Mac and puts WinFix.exe on it. It erases the USB stick, so use an empty one of 8 GB or more. It only ever erases an external disk, and only after you type its name.

  1. Install wimlib. It splits the large install.wim file so it fits on the USB. 
    brew install wimlib
  2. Download the WinFixUsb file for your Mac, then remove the quarantine flag and make it runnable. Use WinFixUsb-macos-x64 instead if your Mac has an Intel chip. 
    xattr -d com.apple.quarantine ./WinFixUsb-macos-arm64
chmod +x ./WinFixUsb-macos-arm64
  3. Practice first. This shows every step and changes nothing. 
    ./WinFixUsb-macos-arm64 --dry-run
  4. Plug in the USB stick and run it for real. Without --iso, it downloads Windows 11 from Microsoft into your Downloads folder. It asks which disk to erase; type its name, for example disk4. 
    ./WinFixUsb-macos-arm64
    To use an ISO you already have, or to name the disk yourself: 
    ./WinFixUsb-macos-arm64 --iso ~/Downloads/Win11.iso --disk disk4
  5. Boot the PC from the USB. Plug the stick into the PC, restart it, and open the boot menu (often F12, F11, F8 or Esc right after power on). Pick the USB stick. In Windows Setup, choose Repair your computer to use the recovery tools, or install Windows again. WinFix.exe is at the top of the USB stick.
